# Final fixes before release (F1–F8)

Each finding got a test first (tagged `// needs-review F<n>` in `tests/Storage.Tests/FinalFixesTests.cs`) that
failed on `d74e2bd` before the fix, except where noted.

| # | Finding | Result | Commit | Test |
|---|---|---|---|---|
| F1 | A read-back that fails after a committed promote is reported as a plain failure | **Fixed.** `ConfirmPromotedAsync` retries a transient read-back (3 tries) and adds `destinationState=complete` to a read-back failure. Staged uploads and `StorageWriteStream.CommitAsync` were affected; the coordinator (`CopyAsync`/`MoveAsync`) already reported such a transfer as committed (`DestinationCommitted = true`), so its test passed before the fix and stays as a regression test. One older test was adjusted to fail the read-back through its retries. | `ee72fbf`, `f4585e3` | `A_read_back_failure_after_a_committed_staged_upload_says_the_destination_is_committed`, `A_transient_read_back_failure_after_a_committed_streamed_write_is_retried`, `A_read_back_failure_after_a_committed_transfer_reports_the_destination_committed` |
| F2 | `TestConnectionAsync` puts exception messages in errors, joins a live session pool; invalid settings give different codes | **Fixed.** Exception type only; FTP and SFTP tests build their own pool and close it; invalid settings are `storage.invalid_content` from both calls (MIGRATION table and docs updated). | `1fcf1c5` | `A_connection_test_step_that_throws_reports_the_exception_type_not_its_message`, `Connection_settings_that_cannot_be_applied_report_the_exception_type_not_its_message`, `Invalid_settings_give_invalid_content_from_both_the_test_and_the_registration`, `A_connection_test_uses_its_own_session_pool_and_leaves_none_behind` |
| F3 | Condition query answers Atomic for MinIO uploads that are staged | **Fixed** (the query now reports what the upload does): `MatchVersion` for uploads is `Atomic` only when the server enforces `If-Match` on both `PutObject` and `CopyObject`, the same rule as `ConditionalUpdate`. | `26a3f0d` | `The_condition_query_for_an_upload_answers_what_a_conditional_upload_on_MinIO_really_does` |
| F4 | `DownloadToFileAsync` Resume appends to any shorter local file | **Fixed.** A Resume download writes to `name.clstorage-partial` with the remote version recorded in `name.clstorage-partial.json`; it resumes only while the remote is still that version (checked again after the tail), and otherwise downloads from the start. The destination is replaced only when the content is complete. | `4734275` | `A_resumed_download_does_not_trust_a_local_file_it_did_not_leave`, `An_interrupted_download_resumes_only_while_the_remote_is_the_version_it_started_from` |
| F5 | Removing a running queue job deletes a NeedsReconciliation record | **Fixed.** The job is kept and `RemoveAsync` returns `storage.conflict`; other outcomes are removed as before. | `1e294ad` | `Removing_a_running_move_whose_copy_committed_keeps_the_job_for_reconciliation` |
| F6 | Failed claims never count toward the store-failure limit; store-failure retry announced as `storage.cancelled` | **Fixed.** Claim failures use the doubling delay and fail the job after 8 in a row; the Retrying event carries `storage.unavailable`. | `3baf764` | `A_job_whose_claim_always_throws_fails_after_the_store_failure_limit`, `A_job_requeued_after_a_store_failure_announces_its_retry_as_unavailable` |
| F7 | `ApplySyncAsync` ignores `DryRun` | **Fixed.** Same checks as a real apply, then every step `NotRun` (or `Withheld`), nothing written, baseline not saved. | `af40dda` | `Applying_a_plan_as_a_dry_run_reports_it_and_changes_nothing` |
| F8 | Part-file lock marker race on FTP/SFTP | **Fixed.** The promote re-check does not close the window: it stops the loser from committing, but both writers may already have appended to the part file. The marker is now read back after 1 s where create-only is not atomic (no `ConditionalCreate`: FTP, SFTP). | `ac3ed36` | `Two_writers_racing_for_a_part_file_where_create_only_is_checked_before_the_write_do_not_both_get_it` |
| F8 | `FlushIdleAsync` is process-wide | **Fixed.** Shared pools record the libraries that used them; stopping a library closes only idle pools no other library has used. | `77a8735` | `Stopping_one_library_keeps_the_lingering_sessions_of_another` |
| F8 | Stale "WebDAV MOVE is atomic" comments in FTP/SFTP | **Fixed** (comments only, no test). | `6967463` | — |
